# X2.10: the path to the summit

*This is the project's working log. It cites some files that aren't in this repo.*

One page. Read this first. Details live in the files named here; status is updated here when it changes.

## The summit
**An exact, general graph machine inside Qwen's weights, that Qwen itself drives, with NYC as its indelible proof.**

Theo, 1 Nov: "We want a graph qwenputer with the city maps as its indelible proof... We don't want to over solve to create a brittle memory... No shortcuts."

We reach it when, on frozen gates:
- real NYC, a rerouted NYC and a relabelled NYC are answered through the merged weights, driven by Qwen, with nothing running outside the model;
- the same checkpoint also takes on 5-10 varied challenges set after NYC, to find its limits (Theo, 2 Nov; this replaces CLUTRR as a requirement), and graph programs chosen after the freeze;
- the headline holds: **close a station, and every affected answer changes, every unaffected answer stays byte-identical, and reopening restores everything**, measured against a weight-editing method on the same questions.

The graph-native hardware then has to match all of this and also run a graph too large for the software version.
